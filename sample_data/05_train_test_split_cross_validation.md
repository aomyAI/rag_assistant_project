# تقسيم البيانات والتحقق المتقاطع (Train/Test Split & Cross-Validation)

## لماذا نقسم البيانات؟
لتقييم قدرة النموذج على التعميم على بيانات لم يرها من قبل، بدلاً من الاعتماد فقط
على أداءه على بيانات التدريب التي حفظها.

## التقسيم الشائع
- Training Set (60–80%): لتدريب النموذج
- Validation Set (10–20%): لضبط المعاملات الفائقة (Hyperparameters)
- Test Set (10–20%): للتقييم النهائي فقط، لا يُستخدم أثناء التدريب إطلاقًا

## K-Fold Cross-Validation
يتم تقسيم البيانات إلى K أجزاء متساوية، وفي كل جولة يُستخدم جزء واحد للاختبار
والباقي للتدريب، ثم يُحسب متوسط الأداء عبر كل الجولات الـ K. يعطي تقديرًا أكثر
موثوقية من تقسيم واحد فقط، خصوصًا عندما تكون البيانات محدودة.
