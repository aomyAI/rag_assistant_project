# التعلم بإشراف مقابل بدون إشراف (Supervised vs Unsupervised Learning)

## Supervised Learning (تعلم بإشراف)
يتم تدريب النموذج على بيانات مُصنَّفة مسبقًا (لها Label أو قيمة هدف معروفة).
أمثلة: تصنيف الرسائل كـ Spam/Not Spam، التنبؤ بسعر شقة بناءً على مساحتها وموقعها.
أشهر الخوارزميات: Linear Regression، Logistic Regression، Decision Trees، Random Forest، SVM.

## Unsupervised Learning (تعلم بدون إشراف)
البيانات غير مُصنَّفة، والهدف اكتشاف أنماط أو تجمعات مخفية بداخلها.
أمثلة: تجميع العملاء حسب سلوك الشراء (Clustering)، تقليل أبعاد البيانات (Dimensionality Reduction).
أشهر الخوارزميات: K-Means، Hierarchical Clustering، PCA، DBSCAN.

## Semi-Supervised و Reinforcement Learning
- **Semi-Supervised**: مزيج من بيانات قليلة مُصنَّفة وكمية كبيرة غير مُصنَّفة
- **Reinforcement Learning**: عامل (Agent) يتعلم عبر التفاعل مع بيئة والحصول على مكافآت أو عقوبات
